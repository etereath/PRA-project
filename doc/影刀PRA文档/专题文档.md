# 字符串


### 字符串的定义

字符串是被 英文双引号 "" 或 单引号 '' 括起来的数字、字母、文字或其他字符的组合，也就是我们通常所说的 "文本"，如：


```None
"影刀RPA"
"机器人流程自动化"
```


### 字符串是有顺序的

字符串的字符是有顺序的，如下图所示，有 **正序和逆序** 两种字符编号方式


![None](https://xybot-oss-cdn.yingdao.com/yddoc/rpa_zh-CN/asset/710949920776896512/39927236-0fde-415b-b4b5-ec10a6e14412/img0.png)


### 字符串的索引

如果把字符串赋值给变量（如 `name = "影刀"`），可以通过 **变量名[编号]** 的方式，获取该编号位置上的字符 ，如`name[0]`会获取字符`"影"`，`name[-1]`获取字符"刀"。


### 字符串的输入

**文本模式** —— 直接输入


![None](https://xybot-oss-cdn.yingdao.com/yddoc/rpa_zh-CN/asset/710949920776896512/df65120a-394b-433b-99c2-c60ae0b83f8b/img1.png)

**表达式模式** —— 加英文双引号或单引号


![None](https://xybot-oss-cdn.yingdao.com/yddoc/rpa_zh-CN/asset/710949920776896512/62fb530e-4d11-4440-b84d-ec5ccb4cbf6d/img2.png)


### 字符串的拼接

使用+号，可以实现字符串的拼接，如`"影刀"+"RPA"`，结果为字符串`"影刀RPA"`，如已经存在一个字符串变量`s = "影刀"`，`s+"RPA"`同样实现了字符串的拼接，得到`"影刀RPA"` 


![None](https://xybot-oss-cdn.yingdao.com/yddoc/rpa_zh-CN/asset/710949920776896512/9002ada5-d571-477c-b867-29670d1e8d31/img3.png)

# 列表


### 什么情况要用列表

一个数字或一段文本，只代表一个数据（如一个人的身高、一个的姓名）

当数据量众多的时候（如全班人的姓名），需要一些盛放数据的容器


### 列表的定义

列表就是一种盛数据的容器,可以将多个数据写入到 **中括号[]** 内，并用 **英文逗号分隔** 开，便构成了一个列表。

e.g. 列表的输入一例：[1,"2",3,4]


### 列表内元素的顺序

列表内元素的排列是有顺序的，分为 **正序** 和 **逆序** 两种编号方式。


![None](https://xybot-oss-cdn.yingdao.com/yddoc/rpa_zh-CN/asset/710949364556349440/03c66018-faf9-437d-96d1-5752cfcfd68a/img0.png)


### 列表元素的索引

通过 **变量名[元素位置]** 的方式， **获取列表对应位置的值**；

如上图中示例，city_of_zhejiang[2] 会获取"台州"；city_of_zhejiang[-2] 会获取"金华"

### 字典的定义

字典是另一种盛数据的容器，它代表了一种 **映射关系**，字典的外部为花括号，内部以 **键值对（键：值）** 的形式存储数据。


```None
students_dict = {01:"小明",02:"小红",03:"小花"}
```


### 字典的用法

可通过 **变量名[键]** 的形式访问到 **对应的** **值**，上文中字典，通过`students_dict[02]`可获取值 `"小红"`。

# 正则表达式


### 正则表达式的引出

使用**正则表达式** 可以从文本中提取自己想要的内容。简单的说，正则表达式就是从文本中，按照一定规律，寻找子文本。例如从`"订单号：123456789"`中获取订单号的数字。可使用【从文本中提取内容】这个指令。


![None](https://xybot-oss-cdn.yingdao.com/yddoc/rpa_zh-CN/asset/710948450255372288/273eb9d4-c681-45de-b131-1d601f79a14c/img0.png)

注:为便于用户使用，对于包含分组的正则表达式，对于每个匹配项，影刀指令默认返回正则匹配到的第一个捕获分组。


### 正则表达式的常用操作符

|  |
|  |
| `.` | 表示任何单个字符 |  |
| `[]` | 字符集，对单个字符给出取值范围 | `[abc]`表示`a`或`b`或`c`，`[a-z]`表示a-z单个字符（任意一位小写字母） |
| `[^]` | 非字符集。对单个字符给出排除范围 | `[^abc]`表示非`a`或`b`或`c`的单个字符 |
| `*` | 前一个字符的0次或者无限次的扩展 | `abc*`表示`ab`、`abc`、`abcc`、`abcccc`等等（匹配 `ab`） |
| `+` | 前一个字符的1次或者无限次的扩展 | `abc+`表示 `abc`、`abccc`、`abcc`、`abccccc`等（不匹配 `ab`） |
| `?` | 前一个字符的0次或者1次扩展 | `abc?`仅表示 `ab`、`abc` |
| `|` | 左右表达式中的任意一个 | `abc|def`表示`abc`、`def` |
| `{m}` | 扩展前一个字符m次 | `ab{2}c`表示`abbc` |
| `{m,n}` | 扩展前一个字符m至n次（含m和n次） | `ab{1,2}c`匹配`abc`、`abbc` |
| `^` | 匹配字符串开头 | `^abc`表示`abc`在一个字符串的开头，即不匹配 `aabc` |
| `$` | 匹配字符串结尾 | `abc$`表示abc在一个字符串的结尾，即不匹配`abcd` |
| `()` | 分组标记内部只能使用`|`操作符 | `(abc)`表示abc ，`(abc|def)`表示`abc`、`def` |
| `\d` | 一位数字，等价于`[0-9]` |  |
| `\w` | 组成单词的字符，等价于`[A-Za-z0-9_]` | 表示字符小写大写的a-z和数字0-9以及下划线`_` |

def get_mean_std(data_list):
    mean_value = sum(data_list)/len(data_list)
    sum_of_squares = 0
    for num in data_list:
        sum_of_squares += (num - mean_value)**2
    std_value = (sum_of_squares/len(data_list))**0.5
    return (mean_value, std_value)

### 选择记录的方式

**自定义捕获创建**：预先定义流程步骤，再为每个步骤进行屏幕捕获，编辑说明通常适用于流程需要先梳理再记录的场景

**智能录制创建**：直接开始记录每一次鼠标键盘的操作，自动截屏并生成操作流程通常适用于对流程了然于胸，确保每个步骤按照执行顺序进行操作的场景

**打开流程文件**：打开指定路径或点选最近编辑的流程文件


### 使用流程录制器


![None](https://xybot-oss-cdn.yingdao.com/yddoc/rpa_zh-CN/asset/710928474755284992/dd41d1de-4b81-4b7e-88ba-7d77624b3c9d/img2.png)


### 界面功能介绍


#### 工具栏

**打开**：打开一个工作流文件，后缀名称pdd

**保存**：保存当前的工作流文件，如果没有则用户选择目录新键一个

**导出**：导出图片：将当前工作流流程图截图并保存

**导出文档**：将工作流详细信息导出到相应模板的word文档，默认为官方文档

**撤销**：针对流程画布中的操作进行撤销行为

**重做**：针对流程画布中的操作进行重做行为

**帮助**：在浏览器中打开帮助链接，跳转到相应网页



#### 画布

**流程**：描述当前任务的一个操作集合

**操作**：每一次输入操作（键盘或鼠标）就会屏幕截图，将这个过程称为一次操作



#### 详情

每一个操作单元的详情，其中动作与决策可以添加文本描述



#### 添加操作

**画线**：给操作添加一条画线，指向其它操作

**动作**：表示流程中的一个动作

**决策**：根据不同的条件值，跳转不同的分支

**结束**：表示当前分支流程的结束

**一键录制**：一键开启录制模式

**操作说明**：每一次鼠标按下或键盘输入都会自动生成一个"动作"

**编辑标题/说明**：补充标题或添加说明信息以使"动作"信息更加清晰完整

**编辑图片**：可以对当前选中动作进行编辑操作

### **常见问题**

**如何删除动作？**

选中需删除的流程，使用“Delete”或“Del”键即可删除

**为什么我添加的画线不见了？**

可能是因为画线自动与其它连线重叠了，请通过拖动动作位置来调整画线的可见性我们会在后期进一步优化画线算法以避免这种情况的发生

**导出的文档可以再进行编辑吗？**

导出的文档可以根据需要自由编辑

**可以删掉多余的流程吗？**

录制过程中的冗余流程，可以通过6.1所述的方式将非必要的流程进行删除我们也建议您这样做，并善用编辑中的图片标注以及补充文档中的操作说明，这将大幅提升文档的可阅读性

**我的流程步骤超出限制了怎么办？**

为提升流程的可读性与确保不影响运行计算机的性能，我们将操作步骤限制在了500个并不计划增加较为复杂的流程，建议进行拆分录制，以便于阅读者更好地理解

### **关于屏幕锁屏**

影刀提供的屏幕锁屏是利用RDP（远程桌面）协议进行屏幕锁屏，这样是为了保证在锁屏状态下，图像，元素等可以继续依赖屏幕渲染而生效，所以如果你的操作系统（例如：Win10家庭版）不支持被远程桌面连接，那就不用考虑使用该指令了，当然对此我们也提供了解决方案，可以使用Python脚本：*ctypes.windll.user32.LockWorkStation()* 来完成锁屏，但无法支持屏幕渲染

当然如果你使用的是Win7系统，就算使用RDP锁屏成功了，也无法支持桌面渲染，这是系统决定的，所以当Win7系统中屏幕锁屏出现问题，也非常建议你使用上述的Python脚本来完成
