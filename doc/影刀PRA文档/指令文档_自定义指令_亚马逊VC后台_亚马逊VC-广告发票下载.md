# 亚马逊VC-广告发票下载


## 描述

此指令用于在亚马逊供应商中心（VC）后台的广告活动管理页面中，筛选指定的日期范围，以抓取广告发票数据或下载对应的PDF发票文件。它帮助用户自动化处理广告费用的对账与归档工作。

## 参数说明


### 输入

- **网页对象**：*网页对象*, 指定用于执行自动化操作的浏览器实例。
- **开始日期**：*字符串*, 指定筛选发票的起始日期，格式为YYYY-MM-DD。
- **结束日期**：*字符串*, 指定筛选发票的截止日期，格式为YYYY-MM-DD。
- **操作类型**：*字符串*, 指定要执行的操作，可选值：scrape（仅抓取数据）、download（仅下载文件）、both（抓取数据并下载文件）。
- **下载文件夹**：*字符串*, 指定下载PDF文件时保存的本地文件夹路径，当操作类型为download或both时必填。
- **文件名前缀**：*字符串*, 指定下载文件名的前缀，用于区分不同批次的文件。

### 场景描述

财务人员每月需要从亚马逊VC后台下载上个月的广告发票PDF，用于报销和财务归档。同时，他们也需要获取发票的明细数据，以便与内部广告投放记录进行核对。使用此指令可以自动完成日期筛选、数据抓取和文件下载的全过程。

### 运行结果

指令成功执行后，系统会根据设定的日期范围，在指定的下载文件夹中生成以预设前缀命名的PDF发票文件，并同时返回抓取到的发票数据列表，供后续处理或记录。


## 常见问题

**问：指令运行时提示找不到网页元素或操作失败，可能是什么原因？**

**答：** 请确保当前浏览器页面已正确导航至亚马逊VC后台的“广告活动管理”下的“发票已付款项”页面。同时，检查提供的“网页对象”是否有效且页面已完全加载。

**问：设置仅下载文件（download）模式时，为什么没有文件被保存？**

**答：** 请确认“下载文件夹”路径已正确填写且存在，同时确保系统对该路径有写入权限。另外，请检查在指定的日期范围内，后台是否存在已付款的广告发票。

**问：输出的“数据列表”是什么格式？如何查看具体内容？**

**答：** “数据列表”通常是一个结构化的字符串（如JSON格式），包含了抓取到的发票信息。您可以在后续指令中使用“记录日志”或“写入文件”等指令将其输出，以便查看具体内容。
