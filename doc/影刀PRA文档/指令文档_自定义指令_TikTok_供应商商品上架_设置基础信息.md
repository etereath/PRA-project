# 设置基础信息


## 描述

该指令实现了填写商品基础信息的功能


![None](https://xybot-oss-cdn.yingdao.com/yddoc/rpa_zh-CN/asset/910815220452139008/29577d96-afa7-459c-8afb-d6871fb5d6a3/image.png)


## 配置


### 输入

**网页对象：web_page，**待操作的网页对象

**商品名称：str，**写入商品的中文名称

**商品品类：str，**写入商品的品类，例 童装 / 女童服装 / 连衣裙 / 礼服裙**或**童装/女童服装/连衣裙/礼服裙

**商品品牌：str，**有则进行填写，无则不需填写


### 输出

无
