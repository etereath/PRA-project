# 运行与排错手册

## 1. 环境准备

- Python：建议使用 `3.11`
- 依赖安装：

```bash
pip install -e .
```

## 2. 常用启动方式

生成样例工作簿：

```bash
python scripts/create_sample_workbooks.py
```

启动 Web 管理页：

```bash
python -m app.cli serve-web --host 127.0.0.1 --port 8765
```

任务预览：

```bash
python -m app.cli preview-tasks ^
  --products data/samples/products.xlsx ^
  --price-rules data/samples/price_rules.xlsx ^
  --listing-rules data/samples/listing_rules.xlsx ^
  --use-mock-ai
```

任务生成：

```bash
python -m app.cli generate-tasks ^
  --products data/samples/products.xlsx ^
  --price-rules data/samples/price_rules.xlsx ^
  --listing-rules data/samples/listing_rules.xlsx ^
  --output data/samples/generated_tasks.xlsx ^
  --use-mock-ai
```

模拟执行并写回日志：

```bash
python -m app.cli simulate-execution ^
  --tasks data/samples/generated_tasks.xlsx ^
  --logs-output data/samples/execution_logs.xlsx ^
  --updated-tasks-output data/samples/executed_tasks.xlsx
```

## 3. Web 页面推荐流程

1. 进入 `任务面板`
2. 先点击“先校验数据”
3. 再点击“预览任务”
4. 核对任务数量与预览表格
5. 点击“确认导出任务”
6. 如需闭环演示，进入 `执行回写` 页面模拟执行

## 4. 常见问题

### 4.1 `invalid headers`

含义：
当前加载的 Excel 首行字段名和系统预期不一致。

排查方式：

- 确认 `products.xlsx`、`price_rules.xlsx`、`listing_rules.xlsx` 没有混用
- 确认 Excel 第一行仍是英文表头，不要改成中文
- Web 页面切换表格类型后，确认路径也跟着切到了对应文件

### 4.2 保存表格时报字段错误

含义：
表格里存在单元格级别问题，例如：

- 必填项为空
- 数字列填了文本
- 布尔列不是 `true/false`
- `internal_sku` 重复

处理方式：

- 看页面顶部错误列表
- 看对应红色高亮单元格
- 修改后重新保存

### 4.3 同一个 SKU 出现多条任务

这在当前设计里可能是正常的。

判断标准：

- 同一 SKU + 不同动作：正常
- 同一 SKU + 同一动作 + 同一平台重复：异常

例如同一商品同时需要 `set_online` 和 `update_price`，会生成两条任务。

### 4.4 `start_web.bat` 启动异常

如果出现乱码或命令被拆断，优先确认：

- 使用的是仓库根目录下最新的 `start_web.bat`
- 没有自己另存为带 BOM 的异常编码版本
- Python 已加入环境变量

可先运行：

```bat
start_web.bat --check
```

### 4.5 浏览器能打开但页面没有数据

通常是样例工作簿还没生成，或路径被改错。

先执行：

```bash
python scripts/create_sample_workbooks.py
```

再检查页面中的默认路径是否存在。
