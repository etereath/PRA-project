# 当前阶段验收清单

## 目标定义

当前阶段目标是交付一个“平台无关、可运行、可测试、可演示”的后端 MVP，并为后续 AI Agent 定价能力与执行器接入预留边界。

## 功能验收

- [x] 已支持商品主数据、价格规则、上下架规则三类 Excel 工作簿
- [x] 已支持 Excel 模板与样例工作簿生成
- [x] 已支持导入校验与结构化错误提示
- [x] 已支持价格规则计算
- [x] 已支持上下架规则判断
- [x] 已预留 AI 定价建议输入输出结构
- [x] 已支持任务预览
- [x] 已支持任务确认导出
- [x] 已支持 Web 管理页
- [x] 已支持 Web 表格编辑页
- [x] 已支持模拟执行与执行日志回写

## 数据与接口验收

- [x] `products` 结构已固定
- [x] `price_rules` 结构已固定
- [x] `listing_rules` 结构已固定
- [x] `tasks` 输出结构已固定
- [x] `execution_logs` 输出结构已固定
- [x] 已保留 `pricing_source`
- [x] 已保留 `decision_trace`
- [x] 已保留 AI 建议相关字段承接能力

## 质量验收

- [x] 已具备单元测试
- [x] 已具备端到端黄金样例回归
- [x] 已提供样例数据
- [x] 已提供快速启动方式
- [x] 已提供字段说明文档
- [x] 已提供运行与排错手册

## 当前阶段已知限制

- [ ] 尚未接 SQLite 或其他持久化数据库
- [ ] 尚未对接真实平台
- [ ] 尚未接入真实 RPA 执行器
- [ ] 尚未实现真实 AI 训练、预测与自动调价闭环
- [ ] 尚未实现多用户、权限、审计体系

## 阶段出口判断

满足以下条件即可认为当前阶段可以收口：

1. 样例 Excel 能稳定生成预期任务
2. Web 页面能完成“校验 -> 预览 -> 导出 -> 模拟执行”
3. 回归测试稳定通过
4. 文档能支撑他人独立运行和排错

## 下一阶段建议

1. 接 SQLite，沉淀任务、日志、规则与主数据
2. 将执行回写从“模拟”升级为“真实执行器适配层”
3. 将 AI 建议从 Mock 升级为真实服务调用
4. 增加人工复核、重试、失败重跑等任务运维能力
