# 决策记录：项目资源与验证预算

状态：已采纳。规范正文只维护在根级 [AGENTS.md](../../AGENTS.md#资源读取与验证预算强制)；本文件不是第二份工作指令。

## 已观察到的浪费模式

- 小改动、文档修改和历史分支推送被扩大为上千项完整 pytest。
- 局部代码检查被扩大为全仓 Ruff，产生大量与当前改动无关的历史输出。
- 全量运行发现旧问题后继续诊断并多次重复运行，偏离原交付目标。
- 多次完整读取旧 `AGENTS.md`、状态页、大型 diff 或 PR 历史，而内容没有变化。
- 简单停止 Worker 被扩展为完整生命周期、窗口和解释器验收。
- 同一 PR 按单条评论反复往返，没有按冻结问题一次汇总整改。
- 为相同语义增加重复 fixture 或测试，用测试数量代替风险覆盖。

## 采用理由

项目选择“定向证据优先、扩大验证需授权”，是为了让验证投入与当前改动风险相称，而不是降低安全标准。用户当前请求已明确要求完整验证时直接复用该授权；高风险改动需要的证明超过预算时必须申请扩大范围，未获授权不能把定向结果写成完整 Gate 已通过。
